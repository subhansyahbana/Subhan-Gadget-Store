Nomor WhatsApp Toko Belum Dikonfigurasi

Sistem mendeteksi bahwa nomor WhatsApp toko masih menggunakan nomor contoh (placeholder) WHATSAPP_NUMBER = "628xxxxxxxxxx".

Untuk mengaktifkan pemesanan langsung:

  1. Buka file script.js di folder proyek.
  2. Cari baris: const WHATSAPP_NUMBER = "628xxxxxxxxxx";
  3. Ganti nilai tersebut dengan nomor WhatsApp toko aktif dalam format internasional (tanpa tanda +, spasi, atau tanda hubung, contoh: 6281234567890).
  4. Simpan berkas dan muat ulang halaman website.
